# IBKR Portfolio X-Ray

Розширення читає позиції з Client Portal Interactive Brokers (або з локального Client Portal Gateway) і в цьому ж браузері рахує:

- **X-Ray** — яка компанія яку частку портфеля займає, включно з акціями всередині ETF;
- **склад** — акції, облігації, золото, інша сировина, крипто, готівка.

Кожна позиція береться у своїй валюті котирування (`USD`, `EUR`, …) і перед розрахунком зводиться курсом ЄЦБ. У шапці звіту суми перемикаються між EUR і USD; під сумою лишається вихідна валюта позиції.

Файли фондів беруться з [TickerInside](https://tickerinside.com/api/) (без ключа). Назовні йдуть лише тікери. Рахунок, кількість і суми лишаються локально. Ордери розширення не виставляє.

UCITS на кшталт VWCE чи CSPX у TickerInside зазвичай немає. Для поширених тікерів підставляється US-фонд того ж класу (CSPX → VOO). Це наближення, не копія складу. Будь-який інший тікер можна зіставити вручну на дашборді.

## Встановлення

1. Відкрийте `chrome://extensions` (або `edge://extensions`).
2. Увімкніть режим розробника.
3. Load unpacked → папка `ibkr-extension`.
4. Відкрийте [Client Portal](https://www.interactivebrokers.com/sso/Login), увійдіть і зайдіть на Portfolio.
5. Якщо портал уже був відкритий до встановлення — оновіть його сторінку.
6. Натисніть іконку розширення → **Зчитати з вкладки IBKR** → **Відкрити аналітику**.

Поки сторінка портфеля сама запитує позиції, розширення підхоплює відповідь і без кнопки.

Локальний gateway (`https://localhost:5000`) працює так само, якщо відкрити його у вкладці. Окреме поле в попапі б’є в gateway напряму; самопідписаний сертифікат надійніше відкрити й підтвердити у вкладці.

Без брокера можна натиснути на дашборді **Приклад** або вставити рядки `ТІКЕР СУМА`.
